# Slotty

時間枠（スロット）にタスクをセットして集中する、シンプルなTodo＆タイマーアプリです。

断続的に進めるルーティンワーク（同じタスクを時間を空けて何度も繰り返す作業）を管理するために作られました。
「次」という専用概念は持たず、常に**「今このスロットでやるタスク」**を明確に見せることをコアバリューとしています。

---

## 主な特徴

- **「今」やるタスクに集中**: 事前にセットしたタスク群を対象にセッション（デフォルト30分）を開始。タスク間の細かい優先度や順序管理に悩まされることなく作業に入れます。
- **直感的なワンタップ操作**: タスク行をタップするだけで「セット / アンセット」を切り替え。セットされたタスクは自動的に上部にグルーピングされます。
- **5色のカラープリセット**: タスク追加時に視認性の高いカラー（みかん、ピーコック、コバルト、バジル、レモン）を選択可能。
- **クイック時間調整**: ヘッダー中央の鉛筆アイコンから、作業時間（分・秒）をその場で自由に変更可能。
- **ローカル自動保存**: タスク一覧や変更したセッション時間はローカルストレージへ自動保存され、アプリ再起動後も状態が維持されます。
- **セッション完了通知**: カウントダウン終了時にアラーム音でお知らせ。完了と同時にアクティブタスクが自動でアンセットされ、次回のスロットへの切り替えがスムーズに行えます。

## インストール（macOS）

1. [Releases ページ](https://github.com/kmcahfne/30m-session/releases) から最新バージョンの `slotty-macos.dmg` をダウンロードします。
2. ダウンロードした `.dmg` ファイルをダブルクリックして開きます。
3. `Slotty` アイコンを `Applications`（アプリケーション）フォルダへドラッグ＆ドロップします。

### 初回起動時の注意（macOS Gatekeeper 警告について）

本アプリはオープンソースの未署名バイナリとして配布されているため、初回起動時に「開発元を検証できないため開けません」等の警告が表示される場合があります。

以下の手順で起動を許可してください：

1. Finder で **「アプリケーション」** フォルダを開きます。
2. `Slotty.app` を **Control キーを押しながらクリック（右クリック）** し、メニューから **「開く」** を選択します。
3. 確認ダイアログが表示されたら **「開く」** をクリックします。

※ 2回目以降は通常通りダブルクリックで起動できます。  
※ ターミナルから以下のコマンドを実行して隔離属性を解除することも可能です：
```bash
xattr -cr /Applications/Slotty.app
```

## 開発・ビルド

### 動作環境
- Flutter SDK 3.28+ / Dart 3.12+
- macOS (Xcode 15+)

### リポジトリのクローンと実行
```bash
git clone https://github.com/kmcahfne/30m-session.git
cd 30m-session
flutter pub get
flutter run -d macos
```

### macOS リリースビルド
```bash
flutter build macos --release
```
