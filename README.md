# loopwork

30分単位で断続的に進めるルーティンワーク(同じタスクを時間を空けて何度も繰り返す作業)を管理するTodoアプリ。「次」という概念は持たず、常に「今この30分でやるタスク」を分かりやすく見せることをコアバリューとする。

## 対象プラットフォーム

- スマートフォンアプリ(iOS優先)
- macOSアプリ(メニューバー常駐)
- 将来的にiOS/macOS間のデータ同期を予定(方式未確定)

## 技術スタック

- Flutter(単一コードベース)

## ステータス

プロダクト仕様確定済み(`docs/spec.md` v0.8)。Flutterプロジェクトの実装は未着手、着手可能な段階(`docs/issues/ISSUE-001-flutter-project-setup.md` 参照)。技術的な実装方式(同期方式・通知実装・状態管理など)はCodexとの実装ヒアリングで確定していく。
